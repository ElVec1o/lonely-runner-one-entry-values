# Programs cited by paper A1 as "computed"

All programs are single-file Rust (std only) or C, exact integer or rational arithmetic (`i128`, `u128`, `i64`), no floating point in any decision (floating point appears only in printed decimals and in the files named below as evidence). Build: `bash code/build.sh` (`rustc -O`, `cc -O2`; nothing is run). Nothing in the paper depends on a computed statement for a Lean-verified one: computed statements are labelled "computed" in the paper's status table.

**Status of this directory.** The sources were compiled once at packaging time (28 programs, 0 failures; nothing was run). The command lines used for the tables of the paper are partly recorded in the `run*.sh` scripts and not in a single reproduction script; no `reproduce.sh` exists, so the claim "every number of the paper is regenerated by one command" is **not** made. The `run*.sh` files call `tools/launch_lite.sh` through `LAUNCH_LITE` and need the binaries that `build.sh` creates. The identification of program and paper statement below is by the packager, from the program headers and the paper's status table; it was not checked by rerunning.
